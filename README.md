# Sistema de Asistencia

Proyecto desarrollado en Java utilizando Programación Orientada a Objetos (POO).

## Funcionalidades

- Registro de estudiantes
- Gestión de asistencia
- Validaciones
- Manejo de excepciones
- Menú interactivo

## Tecnologías utilizadas

- Java
- HTML
- CSS
- JavaScript
- GitHub Pages
